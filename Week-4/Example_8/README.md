# Example 8 - Line Chart with CSV Data

This example reads a CSV file and draws a simple line chart using a time scale and a linear scale.

## Concepts covered
- loading external data with D3
- parsing dates
- scaleTime and scaleLinear
- drawing a path element
- axis generation

## Open it locally
Serve the Week 4 folder with a local web server so the CSV file can be loaded correctly.
