# Week 4 - D3 Basics

This folder contains a small set of beginner D3 examples covering core concepts such as:

- creating SVG elements
- styling and transitions
- binding data to elements
- scales and axes
- loading CSV data and drawing a simple line chart

## Examples

- Example 1: color transition
- Example 2: animated horizontal bar chart
- Example 3: enter/update/exit/remove pattern
- Example 5: scale and axis basics
- Example 6: dimension transition with reshaping elements
- Example 7: scatter plot with point updates
- Example 8: line chart loaded from CSV data

## Notes

Open the HTML files in a browser, or serve the folder locally with a simple static server so that CSV files load correctly.
