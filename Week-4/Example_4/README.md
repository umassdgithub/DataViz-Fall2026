# Example 4 - Linear Scaling

This example demonstrates how to scale data values to fit a viewBox and create reusable coordinate mappings for marks.

## Concepts covered
- reading data values from an array
- using `d3.min()` and `d3.max()`
- creating a linear scale with `d3.scaleLinear()`
- mapping values to SVG coordinates
- animating widths based on scaled data

## Suggested use
Open the page and click the button to update the bar widths using a scale that maps the data range to the chart area.
