# Example 5 - Scale with Axis

This example extends the scaling idea by adding an x-axis to the chart so the mapped values are easier to interpret visually.

## Concepts covered
- linear scales for data-to-screen mapping
- axis generation with `d3.axisBottom()`
- translating groups to position axes in the SVG
- adding a simple chart frame for better readability

## Suggested use
Open the page and click the button to redraw the data and show the scaled bar widths together with the x-axis labels.
